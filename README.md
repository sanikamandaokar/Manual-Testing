

# AI CERTs Learner Portal Testing Documentation

**Comprehensive QA deliverables for the AI CERTs Learner Portal web application.**

## Contents

- **Test Plan**: Objective, scope, test strategy, and risk assessment
- **Test Cases (Excel)**: 56 manually designed scenarios, complete results
- **Bug Reports (PDF, DOCX)**: Description, severity, steps to reproduce, recommendations

## Testing Overview

- Coverage: Functional, UI, and regression testing  
- Browsers: Chrome, Edge, Brave  
- Methods: Manual and Selenium automation  
- Focus: User flows (sign-up, OTP, dashboard, courses), input validation, navigation

## Highlights

- 6 major bugs reported and documented
- Real-world end-to-end validation
- All documents independently prepared by QA engineer

## Usage

1. Review the Test Plan for process and scope.
2. Use the Excel sheet to understand test case coverage/results.
3. Refer to bug reports for defect details and recommendations.
